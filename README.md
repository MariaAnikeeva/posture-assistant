# Ассистент осанки

**Ассистент осанки** — учебный веб-прототип, который использует обученную пользователем модель Google Teachable Machine Pose, чтобы классифицировать положение тела по изображению с веб-камеры.

> Это прототип для самонаблюдения за эргономикой, а не медицинское устройство. Результат модели зависит от обучающих примеров, освещения, ракурса и положения человека в кадре.

## Возможности

- Запуск и остановка отслеживания с веб-камеры.
- Классификация позы по двум классам модели: **«Правильная осанка»** и **«Плохая осанка»**.
- Отображение вероятностей классов и ключевых точек позы.
- Настройка порога уверенности для показа результата.
- Предупреждение на странице после двух последовательных определений класса «Плохая осанка».
- Системные уведомления браузера — только после разрешения пользователя и если браузер поддерживает эту возможность.
- Напоминание о разминке каждые 40 минут во время отслеживания; его можно отключить.
- Светлая и тёмная темы в соответствии с системными настройками.
- Сохранение настройки напоминания в `localStorage` браузера.

## Технологии

- **HTML** — структура страницы и элементы интерфейса.
- **CSS** — внешний вид, расположение элементов и адаптация интерфейса.
- **JavaScript** — логика приложения: камера, вызов модели, результаты, уведомления и события интерфейса.
- **TensorFlow.js** — библиотека машинного обучения, подключаемая через CDN.
- **Teachable Machine Pose** — библиотека для загрузки pose-модели, получения оценки позы и работы с веб-камерой.
- **Vite** — локальный сервер разработки и инструмент сборки.
- **Google Teachable Machine Pose** — сервис, в котором была обучена и опубликована используемая модель.

Приложение работает на стороне браузера: кадры с камеры обрабатываются на устройстве пользователя, а не отправляются на сервер этого проекта. При этом браузер загружает библиотечные скрипты с CDN и файлы модели с сервиса Teachable Machine, поэтому для запуска нужен интернет.

## Требования

- Компьютер с современной версией Chrome, Edge или другим браузером с поддержкой используемых API.
- Node.js LTS и npm — для локального запуска и сборки проекта.
- Подключение к интернету для загрузки библиотек и модели.
- Разрешение браузера на использование камеры.

## Запуск в Windows

1. Установите [Node.js LTS](https://nodejs.org/), если он ещё не установлен. npm устанавливается вместе с Node.js.
2. Скачайте репозиторий или распакуйте архив проекта.
3. Откройте терминал в папке, где находится `package.json`.
4. Установите зависимости:

   ```bash
   npm install
   ```

5. Запустите сервер разработки:

   ```bash
   npm run dev
   ```

6. Откройте адрес, который Vite выведет в терминале. В текущей конфигурации обычно это `http://127.0.0.1:5173`.
7. Нажмите **«Начать отслеживание»** и разрешите доступ к камере.
8. При необходимости отдельно нажмите **«Включить уведомления»** и разрешите их в браузере.

Чтобы остановить локальный сервер, вернитесь в терминал и нажмите `Ctrl+C`.

## Сборка и проверка сборки

Создать production-сборку:

```bash
npm run build
```

Vite создаст папку `dist/`. Её содержимое предназначено для публикации на статическом хостинге. Чтобы локально проверить собранную версию, выполните:

```bash
npm run preview
```

## Модель и классы

Адрес модели задаётся константой `MODEL_URL` в `app.js`. В текущей версии используются классы `Правильная осанка` и `Плохая осанка`. Если модель переобучить или заменить, проверьте адрес модели и названия классов.

Приложение проверяет наличие ожидаемых названий классов, но эта проверка **не измеряет качество модели** и не гарантирует медицинскую или даже практическую точность классификации.

## Ограничения

- Точность зависит от данных, на которых обучалась модель, ракурса камеры, освещения, расстояния и того, насколько хорошо тело видно в кадре.
- Две последовательные классификации уменьшают вероятность единичного случайного предупреждения, но не устраняют ложные срабатывания.
- Браузер может замедлять или приостанавливать работу фоновой вкладки. Проект не гарантирует непрерывный анализ после переключения в другое приложение; после закрытия вкладки отслеживание прекращается.
- Системные уведомления зависят от поддержки браузера и разрешения пользователя.
- Результат модели не является медицинским заключением и не заменяет консультацию специалиста.
