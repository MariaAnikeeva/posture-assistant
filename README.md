# Ассистент осанки

**Ассистент осанки** — учебный веб-прототип, который использует обученную пользователем модель Google Teachable Machine Pose, чтобы классифицировать положение тела по изображению с веб-камеры.

> Это прототип для самонаблюдения за эргономикой, а не медицинское устройство. Результат модели зависит от обучающих примеров, освещения, ракурса и положения человека в кадре.

## Возможности

- Запуск и остановка отслеживания с веб-камеры.
- Классификация по двум классам модели: **«Правильная осанка»** и **«Плохая осанка»**.
- Сглаживание вероятностей и отображение результатов модели.
- Настройка порога уверенности.
- Системное уведомление после трёх последовательных определений класса «Плохая осанка»; повторное уведомление разрешается после пяти последовательных определений класса «Правильная осанка».
- Независимое напоминание о разминке каждые 40 минут во время отслеживания.
- Фоновое распознавание через расширение Chrome Manifest V3 и Offscreen Documents API.
- Кнопки запуска и остановки доступны на сайте и в меню расширения.
- Светлая и тёмная темы в соответствии с системными настройками.

## Как устроен фоновый режим

Обычная веб-страница может замедляться браузером, когда находится в фоновой вкладке. Поэтому фоновая версия использует расширение Chrome:

1. Сайт отправляет расширению команду запуска или остановки через content script.
2. Обычная страница расширения один раз запрашивает разрешение на камеру. Offscreen document не может самостоятельно показать системный запрос разрешения.
3. Offscreen document получает видеопоток и запускает модель Teachable Machine Pose.
4. Service worker отправляет системные уведомления через Notifications API и поддерживает независимый таймер разминки через Alarms API.
5. На сайт передаются вероятности классов и уменьшенное превью кадра. Сам видеопоток не передаётся сайту и не отправляется на сервер проекта.

Отслеживание работает, пока Chrome открыт, компьютер активен, разрешение камеры не отозвано, а расширение не отключено. После закрытия браузера, выключения или сна компьютера непрерывная работа не гарантируется. Это не фоновый сервис операционной системы.

## Установка расширения

В корне проекта выполните команды:

~~~bash
npm install
npm run build
~~~

Сборка создаст:

- **dist/** — сайт для публикации;
- **dist/extension-unpacked/** — папку расширения;
- **dist/posture-assistant-extension.zip** — ZIP-архив расширения.

Чтобы установить расширение в Chrome:

1. Распакуйте ZIP-архив.
2. Откройте страницу расширений Chrome: chrome://extensions
3. Включите **Режим разработчика**.
4. Нажмите **Загрузить распакованное расширение**.
5. Выберите папку **extension-unpacked**.
6. Откройте сайт и обновите страницу.
7. Нажмите **Начать отслеживание** и разрешите расширению доступ к камере.

В меню расширения можно также запустить или остановить отслеживание. Для удаления расширения используйте страницу расширений Chrome.

## Локальный запуск сайта

Требуются Node.js LTS и npm.

~~~bash
npm install
npm run dev
~~~

Откройте адрес, который Vite выведет в терминале. Чтобы проверить production-сборку:

~~~bash
npm run build
npm run preview
~~~

Для локального сайта расширение потребуется дополнительно настроить: добавить локальный адрес Vite в список matches в манифесте и в список разрешённых источников content script и service worker, затем пересобрать расширение и перезагрузить его на странице расширений.

## Технологии

- HTML, CSS и JavaScript — интерфейс и логика сайта.
- Vite — сборка сайта и страниц расширения.
- TensorFlow.js 1.3.1 и Teachable Machine Pose — локальное распознавание.
- Chrome Manifest V3, Offscreen Documents API, Notifications API и Alarms API — фоновая часть.
- fflate — упаковка готового расширения в ZIP.

Модель и её веса загружаются с Teachable Machine; для работы нужен интернет. Видеокадры обрабатываются на устройстве пользователя.

## Ограничения

- Качество распознавания зависит от обучающих данных, освещения, ракурса, расстояния и того, насколько хорошо тело видно в кадре.
- Сглаживание и последовательные определения уменьшают влияние единичных скачков, но не устраняют ложные срабатывания.
- В фоне расширение может продолжать распознавание, но энергосбережение, системные настройки, ограничения камеры или закрытие Chrome могут остановить работу.
- Результат модели не является медицинским заключением.
